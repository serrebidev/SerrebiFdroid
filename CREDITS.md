# Credits

SerrebiFdroid is developer-signed Android APK releases, served through a signed F-Droid repository. Add it in F-Droid under Settings > Repositories > Add repository, using the address and fingerprint from the README.

It follows the upstream [F-Droid repository setup guide](https://f-droid.org/en/docs/Setup_an_F-Droid_App_Repo/). F-Droid is a third-party app store; this repository is only the signed repo it serves.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
